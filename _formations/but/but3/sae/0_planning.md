# :calendar: Planning des séances

La SAÉ se déroule sur **trois séances encadrées**.
Entre deux séances encadrées, vous disposez d'une **séance de travail en autonomie** pour avancer avec votre binôme.

| Séance                         | Objectif                                                                                                                        | VCOD               | EMS                 |
|--------------------------------|---------------------------------------------------------------------------------------------------------------------------------|--------------------|---------------------|
| :mag: **Séance 1**             | Explorer la base de la radio et écrire les requêtes SQL dont les résultats serviront de référence pour valider la migration.    | *22 ou 23 octobre* | *29 ou 30 octobre*  |
| :books: *Autonomie*            | *Terminer les requêtes de la séance 1 et leurs fichiers de référence. Commencer la rédaction du rapport.*                       |                    |                     |
| :thought_balloon: **Séance 2** | Choisir le type de base NoSQL le plus adapté aux besoins de la radio et concevoir la structure de vos données.                  | *3 ou 4 décembre*  | *10 ou 11 décembre* |
| :books: *Autonomie*            | *Poursuivre votre réflexion sur le modèle de données et préparer la migration. Continuer la rédaction du rapport.*              |                    |                     |
| :rocket: **Séance 3**          | Migrer les données de SQLite vers la base NoSQL retenue et vérifier, grâce aux requêtes de la séance 1, que rien n'a été perdu. | *14 ou 15 janvier* | *21 ou 22 janvier*  |

> :bulb: Les séances en autonomie ne sont pas encadrées. L'objectif pour vous est de finir le travail de la séance précédente si vous ne l'avez pas terminé, afin de ne pas arriver en retard à la séance encadrée suivante.
