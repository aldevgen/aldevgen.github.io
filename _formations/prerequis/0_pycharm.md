# Installation de PyCharm

Dans la suite du cours, nous utiliserons l'IDE PyCharm.
PyCharm est un environnement de développement intégré (IDE) pour le langage Python.
Il offre de nombreuses fonctionnalités pour faciliter le développement Python, notamment la complétion automatique, le débogage, et l'intégration avec Git.

Pour cela, il est nécessaire d'installer [PyCharm](https://www.jetbrains.com/pycharm/download) sur votre machine.
