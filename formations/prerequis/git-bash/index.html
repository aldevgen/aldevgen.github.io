Installation de Git Bash

Dans la suite du cours, nous utiliserons des commandes bash. Sous Windows, Git Bash permet d’exécuter ces commandes dans un environnement proche de celui d’un terminal Linux ou macOS. Une grande majorité des serveurs utilisés en informatique fonctionnent sous Linux ; il est donc utile de connaître ces commandes, même lorsque l’on travaille depuis un ordinateur Windows.

Commencer par vérifier si Git Bash est installé sur la machine. Pour cela, cliquer sur la touche Windows, et taper git bash. S’il est présent, passer à la section suivante. Sinon, suivre les instructions suivantes.

Télécharger l’exécutable

Pour installer Git for Windows, il faut télécharger l’éxécutable en cliquant sur Click here to download.

Installer l’exécutable

Une fois téléchargé, ouvrir le logiciel et autoriser Windows à l’installer.

A partir de là, cliquer sur Suivant à toutes les étapes de l’installation.

Sélectionner un éditeur de code pour utiliser avec git : sélectionner vi ou vim.

La configuration de git est (enfin !) finie.

Désormais Git Bash est disponible dans le menu Windows.
